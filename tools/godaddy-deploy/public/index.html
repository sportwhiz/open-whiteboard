STEP 1 OF 4 · CONNECT

Connect your GoDaddy account.

Create a temporary key in GoDaddy, then paste it here. We’ll check which hosting plans you can use.

  1. Open GoDaddy in a new tab.Create my temporary key ↗
  2. Choose Generate Token.Name it “Open Whiteboard setup” and choose 7 days under Expires After. Check each permission listed here.
    What to select under Hosting

    Expand Hosting, then open its sections. Select the individual permissions below.

    • Applicationshosting.application:readhosting.application:createhosting.deployment:execute
    • Source Codehosting.source:readhosting.source:write
    • Domains

      Leave unchecked. Setup uses the address GoDaddy provides.

    • Secretshosting.secret:write
    • Subscriptionshosting.subscription:readhosting.subscription:write
    • Logshosting.log:read

    Select these nine permissions and leave the others unchecked. GitHub access is not needed because setup uploads a ready-made release ZIP.

    Log access lets your coding assistant investigate startup problems. The guided installer does not collect or email raw logs.

    Use a personal access token, not the API key and secret for GoDaddy’s older domain API. Hosting API availability depends on your GoDaddy account.

  3. Choose Create Token, then Copy Token.Come back here and paste it below. Keep the key out of chats and documents.

GoDaddy calls this a “Personal Access Token.” It is different from your GoDaddy password.

This installer sends the key to GoDaddy and keeps it in memory while this page is open. It does not save the key. These permissions cover your GoDaddy account, so use an installer you trust. You can also run this one locally.

The hosted installer records failed setup steps and sends the maintainer a short error report. Reports contain a random support reference, the release version, and an error category. They exclude your key, passphrase, app name, and raw logs. Records are deleted after 30 days without activity. Before a successful connection, only error-category counts are kept. To limit abuse, we keep a daily fingerprint of the key until the setup session has been inactive for 24 hours. It cannot be used to access your GoDaddy account and is never included in reports. Network addresses are used for rate limiting and are not saved in these reports.
